# ERP

`ERP` 是用于集中管理 ERP / 电商运营自动化项目的私有仓库。

当前收录项目：

- `furniture-uploader`
- `jushuitan-link-ops`

## 项目说明

### `furniture-uploader`

定位：

- 家具铺货自动化项目
- 当前以聚水潭 Web + 1688 渠道为第一阶段主线
- 主要使用 Python + Selenium

主目录：

- `furniture-uploader/`

### `jushuitan-link-ops`

定位：

- 聚水潭链接运维项目
- 当前核心任务是批量修改线上商品编码
- 主要使用 Playwright

主目录：

- `jushuitan-link-ops/`

## 当前仓库规则

- 不提交本地私有配置
- 不提交日志、缓存、打包产物
- 不提交 `node_modules`、`dist`、`build`、`__pycache__`

2. 看各项目 `docs/交接文档`
3. 看各项目 `docs/operations/`
