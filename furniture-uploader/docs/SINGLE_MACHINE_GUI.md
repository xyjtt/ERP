# 单机双击版（1 台电脑）

## 适用场景

- 只在 1 台 Windows 电脑上运行 1688 上架任务
- 操作员不希望长期使用命令行

## 首次安装

1. 安装 Python 3.10+（安装时勾选“Add Python to PATH”）。
2. 双击项目根目录的 `安装依赖并启动.bat`。
3. 等待依赖安装完成后，工具会自动打开。

## 日常使用

1. 双击 `启动上架工具.bat`。
2. 在 GUI 中点击“启动Edge调试窗口”，在新浏览器窗口里完成 1688 登录。
3. 选择模板文件（CSV/XLSX/JSON），确认参数后点击“开始上架任务”。
4. 在下方日志窗口查看执行过程和报错信息。
5. 执行后可点“打开运行报告目录”查看 `logs/run_reports` 下的报告。

## 参数说明

- `system`：默认 `1688_direct`
- `platform`：默认 `1688`
- `input-mode`：
  - `variant`：读取 JSON 变体模板
  - `product`：读取 CSV/XLSX 商品模板
  - `auto`：根据文件类型自动判断
- `limit`：处理条数，`0` 表示不限
- `跳过登录`：复用已登录调试浏览器会话
- `禁用钉钉通知`：本地调试建议开启

## 常见问题

- 无法启动（提示找不到 Python）：
  - 重新安装 Python，并确保 `py` 或 `python` 命令可用。
- Edge 调试窗口启动失败：
  - 检查本机是否已安装 Microsoft Edge。
  - 检查端口 `9222` 是否被占用。
- 执行时提示未登录：
  - 先点击“启动Edge调试窗口”，并在打开的窗口内完成登录。
  - 确认进入 `https://myseller.1688.com/` 后再执行任务。
