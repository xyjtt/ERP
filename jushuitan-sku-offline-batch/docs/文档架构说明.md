# 项目文档架构说明

## 1. 采用的文档架构

本项目文档采用 `Diataxis` 四分法组织，并参考 GitLab 文档 topic type 与 Microsoft reference 文档结构进行编排。

文档被拆分为四类：

- `Tutorial`
  面向第一次接触项目的人，帮助快速跑通一个完整场景。
- `How-to`
  面向已经理解项目基本使用方式的人，解决具体任务。
- `Reference`
  面向执行和维护人员，提供准确、完整、可检索的配置和输出说明。
- `Explanation`
  面向开发和维护人员，解释为什么这样设计、有哪些经验、后续如何复用。
